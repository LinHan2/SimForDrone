# Vision

双机视觉感知模块，在 T3 真值跟踪闭环通过后进入主线。

职责：

- 接收 tracker 前视 RGB-D、相机内参与时间戳；
- 输出目标机相对 6D 位姿、时间戳和协方差；
- 支持离线数据集评估与在线推理；
- 为后续 EKF 提供量测，不直接产生飞控命令。

边界：

- 本模块不得直接依赖或调用 `px4ctrl`；
- 相机与位姿时间偏差量化完成前，不接入在线控制闭环；
- 视觉输出通过稳定的数据接口替换 tracking 的真值输入，制导律保持不变。
